# Experience Documentation
There are a few changes in how the experience points are gained in combat. The idea is to make the leveling experience (pun intended) less frustrating, by increasing the amount of experience points provided by the game.   
  

## Changes
- A fainted pokemon will give 30% more experience than the original game  
- Capturing a pokemon will give half of the experience points you would get by defeating it

# Balancing
A way to balance the increased experience points obtained in game is neccessary to avoid making the game trivial.  
So the change is the following. The mechanic of the pokemon not obeying in battle for traded pokemons now it's extended to all Pokemon in the game.  
However the level where adjusted so that your pokemon start not obeying if it has at least two more levels (in the game the text will say that the max level is the level of the next Gym Leader's. Actually there is one more level of grace) than the next Gym Leader (or Champion) highest level Pokemon.  
The following table explain the chances of not obeying
| Overlevel | Disobey chances |
| :--- | :---: |
| Level cap | 0% |
| +1 | 0% |
| +2 | 20% |
| +3 | 40% |
| +4 | 60% |
| +5 | 80% |
| >+5 | 100% |
